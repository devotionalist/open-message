# 生产级工作标准（全角色）

**已定**：六角（架构 / 审计 / 开发 / 测试 / 运维 / 客户）的工作产出，凡进入对应里程碑退出或「生产可用 / 生产 HA」宣称的，**必须达到生产级**；禁止用「草案 / 骨架 / 以后再补 / 聊天里说过」冒充完成。

四目标：[34](./34-architecture-goals.md)。

---

## 0. 「生产级」定义

| 维度 | 生产级意味着 | 非生产级（禁止在退出时残留） |
|---|---|---|
| **完整** | 范围内能力有闭合路径（设计→实现→测→运维→用户） | 只有口号或半截状态机 |
| **可执行** | 他人可按文档复现：编码、断言、值班、集成 | 「详见聊天」「凭感觉」 |
| **可否决** | 有门禁与签字；失败可打回 | 无 Critical 清零仍标完成 |
| **诚实** | 承诺 ≤ 里程碑与 Qa/备份真实能力 | 假 exactly-once、假零错误、假多故障域 |
| **可运维/可观测** | 指标+告警+runbook（运维角）；关键路径有错误分类（开发角） | 无手册告警进值班表 |
| **可回归** | 测试有场景 ID；修复有传播 | 手工点过一次算过 |

**分期允许**：M0/M1 可用「范围内生产级」（例如单 Qa=1 沙箱）——但必须在文档**显式降级叙事**，不得写作「已生产 HA」。

## 1. 分角色生产级条（硬门槛）

### 1.1 架构（Architect）

| 产出 | 生产级要求 |
|---|---|
| 不变量 / 契约 | 写入 `design/*`；索引已挂；无「另定」悬空 |
| 合理性 | 角色/流程/组件/功能均有 [37](./37-design-rationale.md) 五问说明 |
| 流程与图 | [13](./13-flows-and-diagrams.md) 目录挂号 + 图齐或明确指向细章图 |
| 组件角色 | [35](./35-component-roles.md) 做/不做/权威/协作齐全 |
| 四目标 | 对照 [34](./34-architecture-goals.md)；冲突有取舍文 |
| 冻结 | Critical=0；传播表已填（[28](./28-design-audit-requirements.md)） |

**否决**：仅 PPT/聊天定案；关键路径无图无状态机。

### 1.2 审计（Auditor）

| 产出 | 生产级要求 |
|---|---|
| 报告 | 六维全覆盖（或声明局部范围）；每条可证伪 |
| 门禁 | Critical 清零才 PASS；Important 有延期里程碑 |
| 传播 | Fixed 项有扫过路径；无静默复活 |
| 独立 | 非设计作者自嗨勾选（[28 §6.1](./28-design-audit-requirements.md)） |

**否决**：无证据的 PASS；改一处声称全库 Fixed。

### 1.3 开发（Developer）

| 产出 | 生产级要求 |
|---|---|
| 代码 | 对照冻结设计；硬禁令自检（developer.md） |
| 四性 | [30](./30-engineering-quality.md) §5 检查单完成 |
| 测试钩子 | 关键路径有单测；错误码映射齐 |
| 可观测 | 关键路径指标/日志字段按 [32 §7](./32-operations.md) / 30 |
| 偏离 | 书面记录；禁止静默发明协议 |

**否决**：无测主路径；跳过 Fence/Qa；双写 LedgerMeta。

### 1.4 测试（Tester）

| 产出 | 生产级要求 |
|---|---|
| 五层 | 按里程碑 U/F/I/C/S 门禁绿或**有豁免单**（[31](./31-test-strategy.md)） |
| 断言 | 可失败、可重复；幂等阶段测对 |
| Chaos | 范围内 ★/◆ C* 覆盖；含双 Meta 相关则 C13–C15 |
| 与运维 | O* 可抽检；不只 kill 冒充 Drain |

**否决**：「感觉能过」；把 M2 测成跨切主 exactly-once。

### 1.5 运维（Operator）

| 产出 | 生产级要求 |
|---|---|
| Runbook | [ops/](../ops/README.md) 六段结构可照做；命令/Admin 真实存在 |
| 告警 | 每条链 runbook；无孤儿告警进值班表 |
| 演练 | 范围内演练可复现（记录可在本地/CI）；持续流量 |
| 备份 | 宣称生产 HA 前 Backup/Restore 可演练（[28 §7](./28-design-audit-requirements.md)、[32](./32-operations.md)） |
| 护栏 | 隔离组 min、密度上限；缩容不破下限 |

**否决**：骨架 runbook 无步骤；local-k8s 冒充多故障域生产。

### 1.6 客户（Customer）

| 产出 | 生产级要求 |
|---|---|
| 用户文档 | [user/](../user/README.md) 覆盖本里程碑；仅凭其可集成 |
| 语义 | 与 [23](./23-producer-idempotency.md)/[33](./33-customer-usage.md) 一致；无假 exactly-once |
| 示例 | Produce→Consume→Ack 可跑通 |
| 错误 | 可重试分类与切主观感有说明 |

**否决**：必须读内部 design 才能上手；文档超里程碑承诺。

## 2. 里程碑与「生产级」斜率

| 阶段 | 允许 | 仍必须生产级的 |
|---|---|---|
| **M0** | 桩、本地单测 | 契约与禁令文案；不把桩标成生产 |
| **M1** | Qa=1、直连调试、部分 runbook | 已宣称能力的设计+测+用户语义诚实；Drain 路径设计齐 |
| **M2** | 部分 Standby 未上 | Proxy、同 Owner 幂等、半自动 LoadManager、对账草案→可执行；运维告警链手册 |
| **M3** | — | 四订阅、AR、Standby、Offload、跨切主幂等、Backup 演练 |
| **宣称生产 HA** | — | [28 §7](./28-design-audit-requirements.md) 全条 + 六角 [36] 本表签字 |

```text
生产级 ≠ 「文档目录里有个文件名」
生产级 = 可执行 + 可否决 + 可回归 + 承诺诚实
```

## 3. 骨架 → 生产级 升级规则（ops/user 尤其适用）

当前 `docs/ops/runbooks/*`、`docs/user/*` 允许以**骨架**落地目录，但：

1. **对应能力进入里程碑退出前**，该手册必须升到生产级（真实 Admin/指标名、可照做步骤、验证项）。  
2. 握手单须勾选「已升生产级」或「能力未宣称 / 叙事已降级」。  
3. 审计运维维：仍为骨架却宣称生产 HA → **Critical / Important**（相对叙事）。

## 4. 六角相互卡「假生产级」

| 谁卡谁 | 假生产级信号 |
|---|---|
| 审计 → 全员 | 无证据完成、传播假 Fixed |
| 开发 → 架构 | 不可编码仍冻结 |
| 测试 → 开发 | 无断言、测错模型 |
| 运维 → 开发/测试 | 只能杀进程；无 Drain/指标 |
| 客户 → 架构/开发 | 文档不可集成；语义撒谎 |
| 架构 → 开发 | 实现破不变量 |
| 全员 → 审计 | 不可证伪的 PASS |

```text
[ ] 无「仅骨架/仅聊天」项进入本里程碑完成清单
```
