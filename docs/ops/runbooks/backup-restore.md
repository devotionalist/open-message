# Runbook：备份与恢复

规格：[../../design/32-operations.md](../../design/32-operations.md) §9。演练：O14。

## 1. 症状

灾难恢复演练或真实丢 Meta/配置。

## 2. 影响面

恢复窗口全站或控制面不可用。

## 3. 立即隔离

- 宣布维护窗口；停写入（若数据面仍在但 Meta 要回滚）。  
- **禁止**只恢复 OM 或只恢复 OL 后直接开写。

## 4. 步骤

1. 取最近一致备份（OM Meta + OL Meta + 配置版本对齐）。  
2. 恢复 Meta；校验前缀/集群名。  
3. 双 Meta 对账；处理 Orphan/缺口。  
4. 拉起 Broker/Proxy；冒烟。  
5. Bookie 数据：按备份策略（快照/多副本）恢复或依赖存活副本。

## 5. 验证

- 对账干净；E2E；关键 topic 可读。

## 6. 事后

- RPO/RTO 是否达标；备份频率调整。
