# 投递语义（诚实承诺）

本页是对客户的**语义合同**。内部细节：[../design/23-producer-idempotency.md](../design/23-producer-idempotency.md)。

## 1. 一句话

| 你想要 | 怎么做 | 能否宣称 |
|---|---|---|
| 消息尽量不丢（已确认） | 等 SendReceipt；消费侧 Ack 前可重投 | **至少一次**（默认） |
| 超时重发不重复 | 开幂等 + 稳定 `producer_name` + 单调 `sequence_id` | 见下方阶段表 |
| 业务只处理一次 | 生产幂等 **且/或** 业务去重键 | 视阶段；**默认不保证** |

**禁止**：在未满足阶段与配置时对外写「exactly-once / 精确一次」。

## 2. 阶段承诺（必须按发行版本对照）

| 阶段 | 生产侧 | 不承诺 |
|---|---|---|
| **M1** | at-least-once；无服务端去重 | 重发不重复 |
| **M2** | 幂等开启后：**同一 Owner 存活期内**同 seq → 同一 MessageID | **崩溃切主后**仍不重复 |
| **M3** | 幂等开启后：**跨 Owner 切主**对已确认 seq 仍去重（`PERSIST_IDEM=true`，默认开） | 「不开幂等也精确一次」 |

M2 的价值：网络闪断、Proxy 超时重试、连回**仍存活**的 Owner 时安全。  
M3：Go SDK 开幂等 + 稳定 `producer_name` 时，已确认 `sequence_id` 跨 Owner 切主仍返回同一 MessageID。

## 3. Receipt 与「丢」

| 状态 | 集群 | 应用 |
|---|---|---|
| 已 Receipt | 已达 Qa，后续可读（在保留期内） | 可当提交成功 |
| 未 Receipt | 可能已写或未写 | 不确定；按阶段重发 |
| 消费未 Ack | 消息仍可重投 | 处理须防重复 |

二次故障（如丢失 ≥Qa 副本且无冷备）属于已声明的极端风险；不以「永不丢」营销。

## 4. 消费侧

- 默认：**至少一次**投递（失败/重平衡/切主可重投）。  
- Shared / Key_Shared：无「分区内全局只处理一次且保序」的免费午餐。  
- 多 subscription：各组独立，互不影响进度。

## 5. 推荐集成姿势

```text
1. 生产开幂等（稳定 producer_name + sequence_id）
2. SDK 打开默认可重试
3. 关键业务键做消费侧去重（尤其 M2 或未开幂等时）
4. 监控：发送失败率、重试次数、消费重投率 —— 而不是假设零重复
```

## 6. 与运维文档的边界

集群 Drain、备份、扩容不影响本页的语义合同；那些是运维职责（[../ops/README.md](../ops/README.md)）。  
应用侧只需保证：按错误表重试、按阶段理解幂等。
